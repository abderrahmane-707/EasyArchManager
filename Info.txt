--- Web Browsers ---

1. firefox
   Mozilla's open-source, privacy-focused web browser
   Common commands: firefox | firefox URL

2. google-chrome
   Google's proprietary web browser
   Common commands: google-chrome | google-chrome URL

3. brave-bin
   Privacy-focused Chromium-based web browser with built-in ad blocking
   Common commands: brave | brave URL

4. chromium
   Open-source web browser project behind Chrome, Brave, and Edge
   Common commands: chromium | chromium URL

--- Media Players & Viewers ---

5. mpv
   Lightweight, highly configurable command-line/GUI media player
   Common commands: mpv file.mp4 | mpv --loop file.mp4

6. vlc
   Popular, feature-rich cross-platform media player
   Common commands: vlc file.mp4

7. qview
   Fast, minimalist image viewer
   Common commands: qview image.png

--- Office & Document Viewers ---

8. okular
   Universal document viewer (PDF, ePub, images, etc.) by KDE
   Common commands: okular file.pdf

9. onlyoffice-bin
   Comprehensive office suite compatible with MS Office formats

--- Archive & Compression Tools ---

10. 7zip
    High-compression command-line file archiver (7z, ZIP, TAR, RAR)
    Common commands: 7z a archive.7z files/ | 7z x archive.7z

11. peazip-qt-bin
    Feature-rich GUI archive manager and file compression utility

--- Code & Text Editors ---

12. neovim (nvim)
    Hyperextensible, Vim-based terminal text editor
    Common commands: nvim file.txt | :w (save) | :q (quit) | :wq (save & quit)

13. micro
    Modern, intuitive terminal text editor with full mouse support and standard shortcuts
    Common commands: micro file.txt | Ctrl+S (save) | Ctrl+Q (quit)

14. code
    Visual Studio Code (Code-OSS) open-source GUI code editor
    Common commands: code . (open current directory) | code file.txt

--- Compilers & Binary Toolchains ---

15. gcc
    GNU Compiler Collection for C and C++ development
    Common commands: gcc file.c -o app | g++ file.cpp -o app

16. clang
    LLVM-based C/C++ compiler front-end, alternative to gcc
    Common commands: clang file.c -o app | clang++ file.cpp -o app

17. binutils
    Collection of binary analysis tools (objdump, nm, readelf, ar, strip, etc.)
    Common commands: objdump -d app | nm app | readelf -h app

--- Debuggers, Static Analysis & Memory Profilers ---

18. gdb
    The GNU Project Debugger for step-by-step C/C++ code execution analysis
    Common commands: gdb ./app | run | break main | next | print var

19. lldb
    High-performance debugger built on top of LLVM infrastructure
    Common commands: lldb ./app | run | breakpoint set -n main

20. valgrind
    Instrumentation framework for memory leak detection and profiling
    Common commands: valgrind ./app | valgrind --leak-check=full ./app

21. cppcheck
    Static analysis tool for C/C++ code quality and bug detection
    Common commands: cppcheck file.c | cppcheck --enable=all src/

--- Build Systems & Automation ---

22. make
    Build automation utility executing rules defined in a Makefile
    Common commands: make | make clean | make install

23. cmake
    Cross-platform build-system generator (outputs Makefiles/Ninja files)
    Common commands: cmake -B build | cmake --build build

24. ninja
    Small, ultra-fast build system designed to run builds generated by CMake
    Common commands: ninja | ninja -C build

--- Version Control (Git Tools) ---

25. git
    Distributed version control system to track code changes
    Common commands: git init | git add . | git commit -m "msg" | git push | git status

26. sourcegit-bin
    Fast, open-source Git GUI client (SourceGit)

--- CLI File Managers, Search & Navigation Utilities ---

27. ripgrep (rg)
    Ultra-fast recursive line-oriented pattern search tool (grep replacement)
    Common commands: rg "pattern" | rg -i "pattern" dir/

28. fd
    Fast, user-friendly alternative to the `find` command
    Common commands: fd pattern | fd -e txt

29. fzf
    General-purpose interactive command-line fuzzy finder
    Common commands: fzf | vim $(fzf) | history | fzf

30. zoxide
    Smarter `cd` command that learns your most visited directories
    Common commands: z foldername | zi (interactive mode)

31. yazi
    Blazing-fast terminal file manager written in Rust with image preview support
    Common commands: yazi

--- Modern Terminal Substitutes & Utilities ---

32. bat
    `cat` clone with syntax highlighting, line numbers, and Git integration
    Common commands: bat file.txt | bat -A file.txt

33. eza
    Modern replacement for `ls` with colored output, icons, and tree views
    Common commands: eza -la | eza --tree

34. tree
    Displays directory structure as a depth-indented tree diagram
    Common commands: tree | tree -L 2

35. tldr
    Simplified, community-driven, example-based man pages
    Common commands: tldr tar | tldr git commit

--- System Monitoring, Power & Disk Analytics ---

36. btop
    Interactive TUI resource monitor (CPU, memory, disks, network, processes)
    Common commands: btop

37. duf
    Disk Usage/Free space utility with clean, colorful tabular output
    Common commands: duf

38. dust
    Intuitive graphical overview of disk usage (`du` alternative) in terminal
    Common commands: dust | dust -d 2 path/

39. powertop
    Linux tool to diagnose battery consumption and optimize power management
    Common commands: sudo powertop | sudo powertop --auto-tune

--- System Info & Benchmarking ---

40. fastfetch
    Fast system-information display tool (OS, CPU, GPU, memory stats)
    Common commands: fastfetch

41. hyperfine
    Command-line benchmarking tool for measuring command execution speed
    Common commands: hyperfine 'command1' 'command2'

--- Downloaders & Network Tools ---

42. aria2
    Lightweight multi-protocol & multi-source download utility (HTTP/FTP/Torrent)
    Common commands: aria2c URL | aria2c -x16 URL

43. yt-dlp
    Feature-rich CLI media downloader for YouTube and many other video sites
    Common commands: yt-dlp URL | yt-dlp -x --audio-format mp3 URL

44. freedownloadmanager
    Full-featured GUI download manager supporting BitTorrent, HTTP, and HTTPS
