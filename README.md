# EasyArchManager

Bash menu script for Arch Linux to easily select, batch install, update, and remove packages using `pacman` or `yay`

## Features

* **Dual Package Manager Support:** Toggle between `pacman` and `yay`
* **Interactive Search:** Integrates with `fzf` to allow live fuzzy searching across all available `pacman` or `yay` repositories
* **System Actions:** Built-in menu options for batch installation, updating system packages, and removing installed packages

## Prerequisites

* Arch Linux or an Arch-based distribution
